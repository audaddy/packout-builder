# Case photos

Product photos of Milwaukee PACKOUT cases, downloaded from milwaukeetool.com (one per
case, named by the last 4 digits of the part number). They are (c) Milwaukee Tool and are
included only so the app's case selector can show the real cases for personal use.
Do not publish or redistribute them; if this repository is ever made public, delete this
folder - the app falls back to its built-in SVG drawings (`src/assets/packout_images.py`).
